# Handoff: лендинг Tribe (мобильный 2a + десктоп 4a)

## Overview
Одностраничный статичный лендинг продукта **Tribe** — личная записная книжка о людях (кто человек, откуда знакомы, о чём договорились). У страницы **одно целевое действие — перейти в приложение**. Все кнопки ведут на один URL.

- Мобильная вёрстка — вариант **2a** (ширина 390px).
- Десктопная вёрстка — вариант **4a** (ширина 1440px, контент 1200px).
- Стек: **Astro + Tailwind CSS v4**, статическая сборка (`output: 'static'`), без клиентского JS.

## About the Design Files
Файлы в `reference/` — это **дизайн-референсы в HTML**, а не продакшн-код. Они показывают итоговый вид и все значения: инлайн-стили — точные пиксели и цвета. Задача — **воссоздать их в Astro + Tailwind 4** идиоматично: компоненты, утилиты, токены через `@theme`. Копировать инлайн-стили как есть не нужно.

Открывайте файлы в браузере на нужной ширине: `mobile-2a.html` на 390px, `desktop-4a.html` на 1440px.

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры, отступы, радиусы и тексты финальные. Вёрстка должна совпадать попиксельно на 390px и 1440px.

## Interactions & Behavior
- Вся интерактивность — ссылки `<a href={APP_URL}>` на кнопках CTA (их две). Других кнопок, форм и ссылок на странице нет.
- Hover: смена фона кнопки, 150ms. Плюс видимый focus-ring.
- Анимаций в дизайне нет. Если захотите появление секций — только CSS (`@media (prefers-reduced-motion: no-preference)`).
- **Адаптив.**
  - `< 768px` — вёрстка 2a: тянется от 360 до 767px, макс. ширина контента без ограничений, поля 20px.
  - `≥ 1280px` — вёрстка 4a, контент 1200px по центру.
  - `768–1279px` дизайна нет, рекомендация: структура 4a с полями `clamp(24px, 5vw, 120px)`. H1 через `clamp()` от 44 до 64px. Hero и «Выгоды» — в одну колонку до 1024px, сетки на 3 колонки — в одну колонку до 1024px.
- **Разница мобильного и десктопа (как задумано).** В выбранной мобильной версии 2a нет цветных полос и фото — фон сплошной фисташковый. На десктопе 4a полосы и два фото есть. Если мобильную версию нужно привести к 4a, это отдельное решение, уточните у дизайнера.
